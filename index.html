GitHub Pages landing page for hosting manifest.json and OrbSuiteSpoofer.js so the Revenge app can load the plugin and its in-app menu.

Plugin Install URL (Paste into Revenge App)

Setup on GitHub & Revenge App

  1. Put index.html, manifest.json, and OrbSuiteSpoofer.js into your GitHub repository and enable GitHub Pages.
  2. Open the Revenge app → Settings → Plugins, paste the plugin URL, and toggle the plugin ON.
  3. Open the plugin's menu directly inside the Revenge app.
